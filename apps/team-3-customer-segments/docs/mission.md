# Team 3 Mission — Customer Segments

Empower marketers to build and preview audience segments through an intuitive visual rule builder — no SQL or technical skills required. The module turns complex customer targeting into a simple, interactive experience with instant feedback on audience size.

- **Define audiences visually**: Provide a drag-and-drop-style rule builder where marketers combine fields (tier, city, spend, points) with operators to create precise customer segments using AND logic.
- **Preview before you commit**: Evaluate rules against real customer data in real-time, showing the match count and a sample of qualifying customers so marketers can refine criteria with confidence.
- **Manage segments at a glance**: Display all existing segments in a browsable list with customer counts, descriptions, and detail views that show the full rule configuration and matching audience.
