# Team 5 Mission — Rewards Store

Create a member-facing rewards storefront where loyalty members can browse, filter, and redeem rewards using their accumulated points. The store closes the loyalty loop by turning points into tangible value — discounts, products, and experiences.

- **Show spending power upfront**: Display the member's points balance, tier, and name in a prominent header so they immediately know what they can afford before browsing.
- **Browse and filter rewards**: Present a grid of reward cards with category filters (discounts, products, experiences), stock indicators, and smart disable logic that grays out rewards beyond the member's balance.
- **Redeem with confidence**: Provide a clear confirmation dialog showing points cost and balance impact, then update the balance in real-time and log each redemption to a visible history.
