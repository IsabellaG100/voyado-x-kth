Part 1 — AI-Augmented Engineering

AI doesn't replace the developer —
it amplifies them

AI-augmented software engineering means AI works alongside developers at every stage — not just code completion.

SDLC PhaseHow AI helps
RequirementsAnalyze documents, extract features, ask clarifying questions
DesignSuggest design patterns, map data models, generate UX specs
PlanningBreak features into stories, estimate complexity, order by dependency
ImplementationWrite code, follow conventions, use design system tokens
ReviewCheck quality, find issues, auto-fix trivial problems
ShipSuggest commit messages, help with git workflow

This is not "vibe coding". This is structured AI collaboration — the AI follows your conventions, your design system, your architecture.

Part 2 — Your Workflow

Git Branching — How your code ships

One rule: never push directly to main.

main —————————————————————————— (always deployable)
  |
  └— team-5/rewards-store → commits → Push → PR → Review → Merge → Deploy
StepCommand
Create branchgit checkout -b team-{n}/feature-name
Commit oftengit add . && git commit -m "feat: add reward cards"
Pushgit push -u origin team-{n}/feature-name
Create PROn GitHub, target main
MergeAfter mentor approval → CI/CD auto-deploys
